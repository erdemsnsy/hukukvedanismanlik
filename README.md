# ⚖️ Şensoy Hukuk ve Danışmanlık

Bir hukuk bürosunun hizmetlerini, çalışma alanlarını ve bilgilendirici içeriklerini kullanıcılarla buluşturan modern ve responsive web sitesi.

🔗 **Canlı Demo:** https://hukukvedanismanlik.vercel.app/

## 📌 Proje Hakkında

Şensoy Hukuk ve Danışmanlık; ziyaretçilerin hukuk bürosunun çalışma alanlarını inceleyebilmesi, hukuki makalelere ulaşabilmesi ve büroyla kolayca iletişim kurabilmesi amacıyla geliştirilmiştir.

## ✨ Özellikler

- Hukuki çalışma alanlarının tanıtımı
- Bilgilendirici hukuk makaleleri
- Hukuki hesaplama araçları
- Online dilekçe oluşturma sihirbazı
- Kural tabanlı dijital hukuk asistanı
- WhatsApp ve iletişim bağlantıları
- Mobil, tablet ve masaüstü uyumlu tasarım
- Akıcı animasyonlar ve modern kullanıcı arayüzü

## 🛠️ Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript

## 🚀 Yerel Olarak Çalıştırma

Projeyi indirdikten sonra `index.html` dosyasını tarayıcıda açabilirsiniz.

## ⚠️ Bilgilendirme

Sitede yer alan hukuki içerikler genel bilgilendirme amacıyla hazırlanmıştır ve hukuki danışmanlık yerine geçmez.
